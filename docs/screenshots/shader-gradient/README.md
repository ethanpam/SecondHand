# Website design previews

These browser captures show the production build with secondHand's original green-and-white palette and the new grain shader.

- `desktop.jpg`: 1440 × 1000 desktop viewport.
- `mobile.jpg`: 390 × 844 touch viewport.
- `full-page.jpg`: the complete desktop page.
- `privacy.jpg`: the matching privacy page.
- `animation.gif`: a six-second loop of the actual browser-rendered shader, sampled at 10 frames per second and exported at 768 × 516.

The still screenshots use reduced motion for a consistent shader frame. The GIF samples the shader's normal timeline. These files are review assets for PR #31 and are not shipped in the website bundle.
