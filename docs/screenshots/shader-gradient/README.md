# Website design previews

These browser captures show the production build with SecondHand's original green-and-white palette, Bricolage Grotesque and Geist typography, the grain shader, and the new green bear mascot.

The shader extends behind the transparent homepage header with no dividing rules. Its lower-left color stays visible before fading softly into the page background. The hero has no workflow cards, deck, or step controls. The footer retains the React Bits Variable Proximity adaptation and the corrected SecondHand spelling.

- `desktop.jpg`: 1440 × 1000 desktop viewport.
- `mobile.jpg`: the complete responsive hero, captured from a 390 × 844 touch viewport.
- `full-page.jpg`: the complete desktop page.
- `privacy.jpg`: the matching privacy page.
- `footer.jpg`: the large variable-font wordmark and footer.
- `animation.gif`: eight seconds of the actual browser-rendered shader behind the card-free hero. 80 frames, 10 FPS, 768 × 576.
- `wordmark.gif`: four seconds of actual pointer movement over the proximity wordmark. 40 frames, 10 FPS.

The still screenshots use reduced motion for a consistent shader state. The GIFs capture the running production page, not synthetic artwork or a mocked animation. GIF frames have a 100 ms duration and loop indefinitely. These files are review assets for PR #31 and are not shipped in the website bundle.
