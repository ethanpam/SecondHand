# Website design previews

These browser captures show the production build of the React Bits redesign with secondHand's original green-and-white palette, Bricolage Grotesque and Geist typography, and the grain shader.

The shader extends behind the transparent homepage header with no dividing rules. Its lower-left color stays visible before fading softly into the page background. The React Bits Stack adaptation illustrates saved details, desktop approval, and review in Iowa's portal. The footer uses a Variable Proximity adaptation.

- `desktop.jpg`: 1440 × 1000 desktop viewport.
- `mobile.jpg`: the complete responsive hero, captured from a 390 × 844 touch viewport.
- `full-page.jpg`: the complete desktop page.
- `privacy.jpg`: the matching privacy page.
- `footer.jpg`: the large variable-font wordmark and footer.
- `animation.gif`: eight seconds of the actual browser-rendered shader and interactive paper deck, with the next-step button activated by keyboard at two and five seconds. 80 frames, 10 FPS, 768 × 576.
- `wordmark.gif`: four seconds of actual pointer movement over the proximity wordmark. 40 frames, 10 FPS.

The still screenshots use reduced motion for consistent shader and deck states. The GIFs capture the running production page, not synthetic artwork or a mocked animation. The hero recording took 7.985 seconds and the wordmark recording took 3.983 seconds; GIF frames have a 100 ms duration and loop indefinitely. These files are review assets for PR #31 and are not shipped in the website bundle.
