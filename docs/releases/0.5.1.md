# SecondHand 0.5.1

Released October 10, 2026. Download installers and the Chrome extension from
[the public download site](https://secondhand.ethanpam.workers.dev).

This release packages what was merged after 0.5.0, through PR #267:

- **A new extension design** (PR #191): the card and side panel, in six languages.
- **Pantry sign-up questions** (#184): student status, help wanted, sources of income and benefits now,
  answered from saved lists only when exactly one option matches.
- **Today's date** (#258) in "Date ordered", "Date of visit" and "Today's date" boxes, never in a birth,
  start, move-in, due or end date, and never on Iowa's application.
- **Everyday websites** (#267): pages with ads no longer stop Autofill; reading pages such as Wikipedia get
  no card; a household table gets the applicant's name in its first row only; emails shown by example,
  customer and client names, current addresses, Sex and Gender questions, and phone boxes that take only
  digits are filled.
- **Library mode** (#265), which deletes local data after two minutes without activity, and fixes for
  reopening the app while it quits (#256) and for reading documents the same on every display (#260).
- `npm run demo:backup`, a demo runbook in `docs/demo.md`, and a live sweep of everyday websites.

The desktop app and extension are version 0.5.1; the extension build is `2026-10-10.2`. Existing users
should install the new app, refresh its extension files (Chrome extension → Prepare Chrome extension),
reload SecondHand at `chrome://extensions`, and reload their form tab. Passwords and applicant data remain in
the local encrypted vault.

## Build and verification

Build inputs are `da0982f` plus this release's version change.

- Electron 44.5.1; electron-builder 26.15.3; ONNX Runtime 1.30.0. Dependencies were installed with `npm ci`.
- `npm test` passed 1,904 tests (8 optional tests skipped); `npm run check`, the extension, all-websites,
  self-update, desktop UI, Laya, translation, summary, OCR and document UI smokes passed on the merged code.
- Both Mac apps passed the packaged native-messaging smoke (the Intel build under Rosetta). The Apple Silicon
  app restored and unlocked an encrypted demo backup and reported extension build `2026-10-10.2`.
  Both DMGs passed disk-image verification.
- The Windows native relay was compiled from the unchanged `desktop/native-launcher.cs` with Mono 6.8 in the
  pinned image `electronuserland/builder@sha256:dfb75f33587cdbd075f19380fb1f09c98fda304c0cc26df4ac48f9e7c5302558`.
  electron-builder built the NSIS installer on macOS. Its 349 payload files were extracted and checked: the
  relay and the extension match their build inputs, and only Windows x64 ONNX binaries are included.

On October 10, 2026, a GitHub Actions Windows runner (windows-latest) checked the published installer: its download
matched `SHA256SUMS.txt`; a silent install put the app, the relay, the extension and the OCR assets in place; the
native messaging smoke passed through the installed `secondHand-native.exe`, with the app running and with the relay
starting the app; the installed app restored and unlocked the fictional demo backup and reported extension build
`2026-10-10.2` with Laya ready; and a silent uninstall removed it (run 38062964145). The OCR UI and Chrome itself
(loading the extension and filling a form) have not been run on Windows.
Both platforms remain unsigned early-access builds; Mac builds are not notarized. Laya is unavailable on Intel
Macs; their OCR, saved information, and recognized-field autofill remain available. No live benefits
application or real applicant data was used in release QA.
