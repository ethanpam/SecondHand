# SecondHand 0.5.0

Released October 6, 2026. Download installers and the Chrome extension from
[the public download site](https://secondhand-download.khoidoan00.chatgpt.site).

This release packages the general-form autofill changes merged in PR #209:
encrypted custom answers with explicit question aliases, more editable controls
(including open shadow roots), and opt-in **Fill and continue** for recognized
multi-page forms. Continuation uses saved answers and pauses when information is
missing or a protected action needs the applicant. CAPTCHA, consent, signatures,
and final submission remain manual. Recognition is not a promise to support every
form or custom widget.

The desktop app and extension are version 0.5.0; the extension build is
`2026-10-06.11`. Existing users should install the new app, refresh its extension
files, reload SecondHand at `chrome://extensions`, and reload their form tab.
Passwords and applicant data remain in the local encrypted vault.

## Build and verification

Build inputs start at `b31b5a9de6f347ede489a31cd8d62beb344a08c4`, with this release's
version changes and explicit platform packaging allowlists. Those allowlists fix
electron-builder's platform overrides including old release artifacts when using
a versioned output directory. Application archives contain only the desktop,
renderer, shared code, runtime dependencies, and application metadata.

- Electron 44.4.5; electron-builder 26.15.3; ONNX Runtime 1.30.0.
- Source checks and 381 focused release/extension tests passed. The feature's
  pre-merge full run passed 1,740 tests, with 10 optional tests skipped.
- Apple Silicon and Intel packaged apps passed the synthetic scanned-PDF OCR
  review/save flow and running-app Chrome native messaging smoke checks. The
  Intel build ran under Rosetta on an Apple Silicon Mac.
- The Apple Silicon packaged app passed custom-answer creation, explicit save,
  encryption, lock/unlock, and process restart checks with an isolated vault.
- Both DMGs passed disk-image verification. Packaged source, extension files,
  and OCR assets were checked against their build inputs.
- Windows was cross-built using the pinned official image
  `electronuserland/builder@sha256:dfb75f33587cdbd075f19380fb1f09c98fda304c0cc26df4ac48f9e7c5302558`.
  Mono 6.8 interpreter mode compiled the unchanged native relay. The standard
  macOS electron-builder prepackaged NSIS path finalized the installer after
  Wine under ARM emulation could not run the intermediate uninstaller builder.
  Both NSIS and embedded archive integrity checks passed; all 340 extracted
  payload files matched the verified Windows app, including 217 OCR assets.

Windows installation, uninstallation, OCR UI, and Chrome integration have not
been run on a Windows machine. Both platforms remain unsigned early-access
builds; Mac builds are not notarized. Laya is unavailable on Intel Macs; their
OCR, saved information, and recognized-field autofill remain available. No live
benefits application or real applicant data was used in release QA.
